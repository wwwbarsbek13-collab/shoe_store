## 1. Цель работы

Создать пользовательские функции для расчётов и форматирования в SQLite, реализовать аналоги процедур на Python с транзакциями, подготовить примеры PL/pgSQL для PostgreSQL и проверить ограничения базы данных.

Работа выполнена в **едином проекте `shoe_store`** из предыдущих дней. Рабочая база `db/shoe_store.sqlite` сохранена без изменения таблиц, связей и данных. В PDF эта работа называется «УП.11 №10», но тема внутри указана как «Тема 9». Для совместимости использованы имена файлов из задания: `10_report.md`, `procedures_functions.py`, `procedures_functions.sql`.

## 2. Разница между функцией и процедурой

Функция получает входные значения и возвращает результат, например стоимость товара. Процедура выполняет последовательность действий, например оформление заказа и списание остатков. В PostgreSQL функция создаётся через `CREATE FUNCTION` и может вызываться в `SELECT`, а процедура через `CREATE PROCEDURE` и вызывается командой `CALL`. В SQLite хранимых процедур нет: их работу выполняют Python-функции с транзакциями. Пользовательские SQL-функции подключаются с помощью `conn.create_function()` для каждого соединения отдельно.

## 5. Блок 2. Эмуляция процедур и транзакции

**`create_order(conn, user_id, stock_item_id, quantity)`** проверяет клиента, существование товарной позиции и наличие остатка. Затем в **одной транзакции** уменьшает остаток через `UPDATE ... WHERE quantity_available >= ?`, вставляет заказ с текущей датой и позицию с исторической ценой из `products`. При неудаче вызывается откат и возвращается `False`. При успехе возвращается `True`.

**`update_stock(conn, stock_item_id, quantity_sold)`** списывает нужное количество. Если товар отсутствует, количество неверное или остатка не хватает, выбрасывается `ValueError`, а транзакция откатывается. Это предотвращает отрицательные остатки.

**`get_sales_report(conn, start_date, end_date)`** выполняет `JOIN` таблиц `orders` и `order_items` и сумму `SUM(quantity * price)` для заказов в указанном диапазоне. Проверяет даты формата `YYYY-MM-DD` и возвращает текстовую строку.

### Демонстрационные результаты (только временная копия SQLite)

- Исходное количество заказов: **3**.
- Исходный остаток первой товарной позиции: **9**.
- Создание нового заказа на 2 единицы: **успешно**, количество заказов увеличивается на 1, остаток уменьшается на 2.
- Заказ на миллион единиц: **отказ**, количество заказов и остаток остаются неизменными.
- Отдельное списание одной единицы: **успешно**, остаток уменьшается на 1.
- Попытка списать миллион единиц: **`ValueError`**, остаток не изменён.
- Принудительная ошибка вставки `order_items`: вся транзакция откатывается, заказ не остаётся в базе, остаток восстанавливается.
- Функции поддерживают вложенные вызовы внутри уже открытой транзакции через `SAVEPOINT`, не фиксируя изменения внешней транзакции.
- Отчёт за интервал 2020–2035: **С 2020-01-01 по 2035-12-31 продано товаров на сумму 32739.90 руб.**

Тесты транзакций выполнялись в **копии БД в оперативной памяти** (`sqlite3.backup()`), поэтому исходный файл базы не менялся.
