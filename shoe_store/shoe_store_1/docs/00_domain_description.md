# Описание предметной области «Чудо Обувь»
Торговая компания «Чудо Обувь» занимается продажей обуви и имеет сеть магазинов. Приложение для заказа обуви даёт клиентам компании возможность выбрать и заказать одну или несколько пар обуви из каталога различных моделей и размеров обуви в торговом зале. На данный момент услуга предоставляется только для обуви, в дальнейшем возможно расширение ассортимента товаров за счёт аксессуаров.

# Функциональные требования

1. В каталоге должно храниться актуальное доступное для заказа количество товарных позиций, то есть сочетаний модели и размера.
2. Для каждой модели в каталоге должно сохраняться изображение.
3. Пользователь должен иметь возможность выбрать из каталога одну или несколько пар обуви доступного размера и модели.
4. В интерфейсе должен быть доступен просмотр списка заказов с отображением ключевой информации: дата заказа, ФИО клиента.
5. Должно быть реализовано управление заказами.

# Авторизация

Вход в систему следует производить только по логину, указанному в списке пользователей системы. Пароль при этом вводить не требуется. После успешной авторизации пользователь получает доступ к соответствующим функциям системы.

# Роли пользователей

**Неавторизованный пользователь** — просмотр каталога товаров (без фильтрации, сортировки, поиска).
**Авторизованный пользователь** — просмотр каталога (с фильтрацией, сортировкой, поиском); оформление заказов: добавление/удаление товарных позиций, изменение количества.
**Менеджер** — всё, что авторизованный пользователь + просмотр заказов, состава конкретного заказа; добавление новых заказов и удаление существующих.
**Администратор** — всё, что менеджер + редактирование заказов.

# Взаиморасчёты

Взаиморасчёты торговой компании с клиентами осуществляются в рублях.
