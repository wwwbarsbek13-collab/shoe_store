# Нормализация до 3НФ

## 1НФ ✅
Все атрибуты атомарны. Размеры — отдельные записи в `sizes`, не строка.

## 2НФ ✅
Составные ключи: `stock_items` (product_id + size_id), `order_items` (order_id + stock_item_id). Неключевые атрибуты зависят от полного ключа.

## 3НФ ✅
Транзитивных зависимостей нет:
- роль → справочник `roles`
- размер → справочник `sizes`
- цена → текущая в `products`, историческая в `order_items`

| Сущность | 1НФ | 2НФ | 3НФ |
|---|---|---|---|

## Аномалии без нормализации
- **Вставка:** нельзя добавить товар без заказа
- **Обновление:** смена фамилии → обновление многих строк
- **Удаление:** удаление заказа → потеря клиента

## Устранение транзитивных зависимостей
| Зависимость | Решение |
|---|---|
| role_name → role_id → user_id | Справочник `roles` |
| size_value → stock_item_id | Справочник `sizes` |
| Текущая цена → order_items | Историческая `price_at_order` |
