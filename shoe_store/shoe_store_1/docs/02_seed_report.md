# Отчёт о тестовых данных

| Таблица | Количество записей | Описание |
|---------|-------------------|----------|
| roles | 3 | администратор, менеджер, авторизованный пользователь |
| users | 3 | admin, manager, user |
| products | 5 | разные модели обуви |
| sizes | 5 | 36, 37, 38, 39, 40 |
| stock_items | 10 | сочетания товаров и размеров |
| orders | 3 | заказы от разных пользователей |
| order_items | 6 | по 1–2 позиции в каждом заказе |

Связь заказов с пользователями: каждый заказ содержит user_id, ссылающийся на таблицу users. Это позволяет при выборке узнать ФИО клиента.
