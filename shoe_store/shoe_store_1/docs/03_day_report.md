## Принятые решения
- **Имена не менялись** — схема из дня 2 уже соответствовала требованиям (латиница, lower, snake_case, мн. ч. таблиц, `_id`).
- **CHECK на длину логина (3–20)** — защита от пустых и слишком длинных.
- **CHECK на цену (< 1 млн)** — защита от опечаток.
- **CHECK на размер (20–50)** — реальный диапазон обуви.
- **CHECK на дату через `date()`** — проверка ISO 8601.
- **9 индексов на FK** — ускоряют JOIN; плюс индексы на сортировку/фильтрацию.
- **RESTRICT** для ролей, пользователей, товаров, размеров — защита данных.
- **CASCADE** для order_items при удалении order — состав не нужен без заказа.
