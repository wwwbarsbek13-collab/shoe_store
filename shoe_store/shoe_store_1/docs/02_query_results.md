# Результаты простых запросов

## 1. Пользователи с ролями
Выводит список всех пользователей с названиями их ролей.
Результат: 3 строки (admin — администратор, manager — менеджер, user — авторизованный пользователь).

## 2. Список всех товаров
Выводит все товары с категорией, производителем и ценой.
Результат: 5 строк.

## 3. Список всех размеров
Выводит все доступные размеры обуви.
Результат: 5 строк (36–40).

## 4. Заказы с ФИО клиентов
JOIN между orders и users. Выводит заказы с полным именем клиента.
Результат: 3 строки.

## 5. Товарные позиции с товаром и размером
JOIN между stock_items, products и sizes.
Результат: 10 строк.
