# Словарь терминов «Чудо Обувь»

| Термин | Определение | Пример |
|---|---|---|
| Предметная область | Часть мира для автоматизации | Торговая компания «Чудо Обувь» |
| Сущность | Объект, о котором хранится информация | Товар, заказ, пользователь |
| Атрибут | Характеристика сущности | Наименование, цена |
| Первичный ключ (PK) | Уникальный идентификатор записи | `product_id`, `order_id` |
| Внешний ключ (FK) | Ссылка на запись в другой таблице | `role_id` в `users` |
| Связь | Отношение между сущностями | Пользователь оформляет заказы |
| Кардинальность | Количество связей (1:1, 1:N, M:N) | users 1 — N orders |
| Нормализация | Устранение избыточности и аномалий | Разбиение на 7 таблиц |
| 1НФ | Атомарность значений | Один размер — одна запись |
| 2НФ | Зависимость от полного ключа | `quantity` в `stock_items` |
| 3НФ | Нет транзитивных зависимостей | Роль в справочнике `roles` |
| Транзитивная зависимость | Неключевой атрибут зависит от неключевого | `role_name` → `role_id` |
| Аномалия вставки | Нельзя добавить одно без другого | Товар без заказа |
| Аномалия обновления | Противоречия при обновлении | Фамилия клиента в разных строках |
| Аномалия удаления | Потеря данных при удалении | Удаление заказа — потеря клиента |
| Товарная позиция | Сочетание модели и размера | Кроссовки N, размер 42 |
| Каталог | Список доступных товаров | Список моделей обуви |
| Справочник | Таблица уникальных значений | `roles`, `sizes` |
| Составной ключ | Ключ из нескольких полей | `product_id` + `size_id` |
| Ссылочная целостность | Корректность внешних ключей | FK не ссылается на несуществующее |
