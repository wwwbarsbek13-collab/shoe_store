## Принятые решения и обоснование
 **INTEGER для идентификаторов** — целые числа, автоинкремент, высокая производительность.
 **TEXT для дат** — SQLite не имеет отдельного типа DATE; формат ISO 8601 обеспечивает корректную сортировку.
 **NUMERIC для цен** — важна точность до копейки, NUMERIC хранит фиксированное число знаков после запятой.
 **UNIQUE для логина** — система различает пользователей по логину, дубликаты недопустимы.
 **DEFAULT для даты заказа** — автоматическая подстановка текущей даты при создании заказа.
 **RESTRICT для заказов** — нельзя удалить пользователя, пока у него есть заказы.
 **CASCADE для состава заказов** — при удалении заказа автоматически удаляются его позиции.
